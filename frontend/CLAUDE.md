# Frontend — Angular 19

## Stack
- Angular 19 (standalone components)
- TypeScript strict mode — no `any` types ever
- SCSS for styling
- Angular Signals for state
- HttpClient for API calls
- Reactive Forms for forms

## Architecture
- Standalone components only — no NgModules
- Services for all API calls and business logic
- Components are dumb where possible — logic lives in services or smart parent components
- Lazy loaded routes for all feature areas

## Naming
- Components: `boat-card.component.ts`
- Services: `boat.service.ts`
- Models/interfaces: `boat.model.ts`
- Selectors: `app-boat-card`

## Conventions
- Always type API responses — define interfaces in `models/`
- Use `inject()` function, not constructor injection
- Async pipe in templates — avoid manual subscriptions where possible
- Always unsubscribe or use takeUntilDestroyed()
- No logic in templates beyond simple conditionals

## Styling
- Use existing SCSS variables and mixins from `src/styles/`
- Never hardcode colors or spacing — use design tokens
- BEM naming for CSS classes

## Testing
- Jasmine for unit tests
- Test services and components separately
- Mock HttpClient with HttpClientTestingModule
- Mock services with NonTypedSpyObj
- Test naming: `should [expected behavior] when [condition]`
- Always test: renders correctly, handles loading state, handles error state

## What NOT to do
- No `any` types
- No direct DOM manipulation
- No logic in templates beyond `*ngIf` / `@if` equivalents
- No hardcoded API URLs — use environment files
